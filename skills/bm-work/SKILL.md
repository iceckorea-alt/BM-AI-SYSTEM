# 비엠업무 (BM 업무 진입 스킬)

스킬 v3.11 · 2026-11-06 · 이 스킬은 '어디서부터 읽는가'만 안내한다. 규칙 원본은 GitHub `governance/BM_CORE.md`이며, 이 스킬과 다르면 원본을 따른다.

## 시작
1. Google Drive 연결 도구로 공유드라이브 `BM` 루트의 `BM_STARTER`를 읽는다(Google Docs). 개인 Drive·백업·LEGACY 파일과 98·99 폴더를 대신 읽지 않는다.
2. 매번 읽는 규칙은 STARTER 0장뿐이다. `governance/BM_CORE.md`는 0장에 없는 세부가 필요할 때 raw 주소로 해당 장만 읽는다(github.com 페이지가 아니라 raw).
0. 조회만 할 때(`오늘 할 일`·`현황`·`누구 할 일`)는 STARTER 다음 INDEX `접속요약` 탭(또는 `열린할일` 탭)과 `신규메일` 탭만 읽고 답한다.
3. INDEX `접속요약` 탭과 `신규메일` 탭을 읽어 진행 프로젝트와 메일 현황을 파악한다. 접속 단계에서 각 READ를 열지 않는다.
4. 사용자가 프로젝트를 지정하면 그 READ와 `열린할일` 탭의 그 프로젝트 줄을 읽고 판단한다. LOG와 원본은 필요할 때만 연다.
5. 업무 종류에 맞는 OPS 파일만 추가로 읽는다(BM_CORE 9장). 같은 채팅에서 이미 읽은 규정은 다시 읽지 않는다.
6. 프로젝트가 아닌 문서(브랜드 GUIDE·플랫폼 READ·SNS 등)는 INDEX `공통문서` 탭 링크로 연다. Drive 전체 검색은 지도에 없을 때만 한다. 사업 기회(기본계획·공고) 질문은 INDEX `사업발굴` 탭과 `_요약` 문서만 읽는다.
7. 읽지 못한 것은 '못 읽음'으로 보고하고 추정하지 않는다.

## 시작 보고 (짧게)
- 읽기 성공·실패: STARTER / INDEX (/ READ) / 신규메일 탭(갱신 시각)
- 프로젝트 표는 소속별로 나눈다. 표마다 `프로젝트 | 담당 | 상태 | 다음 할 일`. 담당 미지정은 그대로 표시한다.
  1) BM서울 표  2) BM인천 표
- 신규메일: 소속별로 `수신일 | 보낸 곳 | 요약 | 프로젝트 | 처리`. 6시간 넘게 갱신 안 됐으면 `메일 목록이 오래됨 — 메일 담당 AI에서 '메일 확인'` 한 줄을 붙인다.
- 책임자 미지정, 기한이 오늘이거나 지난 할 일, 일정이 지났는데 `진행`인 행은 한 줄 경고한다.
- 마지막에 `오늘 뭐부터 할까요?`

사용자가 처음부터 특정 업무를 지시했으면 목록을 생략하고 바로 그 프로젝트로 들어간다.

## 작업 중
- 기록은 지시한 사람의 실명으로, 대신 적은 줄에는 `(Claude 기록)`·`(GPT 기록)` 표시. 지시자를 모르면 묻는다.
- 확정 변경은 명령 없이 저장: READ는 새 값으로 덮어쓰고(최신본 확인 → 바뀐 줄만 → 재확인), 이전 값·이유는 LOG 끝에 한 줄 추가. 할 일은 INDEX `할일` 탭에만 쓴다(추가=새 행·다음 ID, 변경=그 ID 칸만, 완료=상태 `완료`+LOG). 0장 상태가 바뀌면 INDEX `진행상태`도 맞춘다(권한 밖이면 업데이트요청).
- 작업이 저장·확인으로 끝났고 대화가 길어졌으면 `새 채팅에서 비엠접속 → 프로젝트명 이어서`를 권한다.
- 규정·구조 변경을 제안할 때는 읽는 양 전후를 수치로 함께 낸다.
- 문서는 STARTER·INDEX 링크로 열고 Drive 전체 검색은 지도에 없을 때만 한다.
- 메일 담당 AI는 OPS_MAIL에 따라 INDEX `메일수집` 탭을 먼저 읽고 판단한다. 다른 AI는 Gmail·`메일수집`을 읽지 않고 INDEX `신규메일`만 본다.
- 실무문서는 현재 작업본 1개만 둔다. `초안`·`v1`·`v2`·`검토안` 과거본은 프로젝트 `99_이전버전`에 임시 보관하고 평소 읽지 않는다. 운영확정·제출 완료 후 대표의 `정리`·`마감` 지시가 있으면 일반 작업 초안만 삭제 가능하며 공식 증빙은 보존한다.
- 98_아카이브·99_시스템백업은 사용자가 지시하지 않으면 읽지 않는다.
- 완료보고에 `READ 저장·확인 완료 / READ 변경 없음 / READ 저장 미완료 — 사유` 중 하나를 표시한다.
- `매뉴얼`·`도움말` 등 → `guides/BM_AI_USER_QUICK_GUIDE.md`. `마감` → `governance/ops/OPS_CLOSING.md`. `메일 확인` → `governance/ops/OPS_MAIL.md`.

## 한계
기존 연결 도구를 호출하는 지침형 스킬이다. 백그라운드 실행·결재 자동 감지는 없다. 연결되지 않은 시스템(Docswave 등)은 연결된 것처럼 말하지 않는다. 설치된 스킬 사본이 이 원본과 다르면 원본을 따른다.
