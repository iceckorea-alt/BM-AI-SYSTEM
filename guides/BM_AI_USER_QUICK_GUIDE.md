# BM AI 사용자 퀵가이드 — 직원용

**성격:** BM AI 플러그인·AI 직원 사용자를 위한 간편 사용안내  
**규정 지위:** 사용자 안내서이며 운영규정 원본을 대체하지 않는다. 충돌 시 GitHub `BM_DIGITAL_1.0.md`, `BM_AI_AGENTS_.md` 등 최신 공식 규정을 우선한다.

## 1. 처음 시작할 때
BM 업무를 시작하면 AI가 다음 순서로 공식 원본을 확인한다.

`BM_STARTER → GitHub 최신 규정 → BM_PROJECT_INDEX → PROJECT_READ → 실제 원본`

직원은 파일 위치를 외울 필요가 없다. 프로젝트명이나 하고 싶은 일을 말하면 AI가 먼저 찾아야 한다.

## 2. 자주 쓰는 말

### 프로젝트 열기
- `홍대 캔버스 프로젝트 열어줘`
- `캠프마켓 AI강의 현재 상태 보여줘`
- `이 프로젝트 다음 할 일 알려줘`

### 업무 수행
- `이 자료 기준으로 공문 작성해줘`
- `실행계획안 만들어줘`
- `현재 진행상황 정리해줘`
- `결과물 저장 위치 알려줘`

### 작업 결과 저장
- `작업 결과 저장`
- `현재 상태 저장`
- `READ 업데이트`

위 표현은 같은 의미다.

AI는 확인된 결정, 실제 완료된 일, 현재 진행상태, 미결사항, 다음 해야 할 일, 결과물 링크를 PROJECT_READ에 반영하고 다시 읽어 저장 여부를 확인한다.

### 프로젝트 마감
- `마감`
- `프로젝트 마감`
- `마감요청`

마감이라고 해도 즉시 종료되지 않는다.

`결과보고서 확인·작성 → READ 최종정리 → 마감요청 → Docswave 결재 → 승인 후 종료`

결과보고서가 없으면 AI가 DOCX 결과보고서 작성을 시작한다. 확인되지 않은 참여인원·예산·성과·변경사항 등은 추정하지 않고 직원에게 질문한다.

## 3. 매뉴얼 보기
다음 표현은 모두 같은 도움말 명령으로 처리한다.

- `매뉴얼`
- `메뉴얼`
- `퀵가이드`
- `사용법`
- `도움말`
- `도움`

AI는 이 퀵가이드의 핵심 사용법을 채팅에 보여준다.

`자세한 매뉴얼`, `전체 가이드`라고 하면 최신 원본 링크와 전체 내용을 안내한다.

## 4. 직원이 직접 바꾸지 않는 것
일반 직원·프로젝트 AI는 다음을 임의로 변경하지 않는다.

- 중앙 프로젝트 대장의 공식 `프로젝트` 탭
- 프로젝트 삭제
- 대량 파일 이동
- 공유범위·관리자권한
- 비밀번호·토큰·OTP·복구코드 등 인증정보

프로젝트 대장 변경이 필요하면 AI가 `업데이트요청` 절차를 사용한다.

## 5. AI가 모르는 정보가 있을 때
AI는 추측하지 않아야 한다.

다음처럼 말하면 된다.
- `모르는 건 물어봐`
- `공식 원본 기준으로 확인해`
- `추측하지 말고 확인된 것만 작성해`

AI가 필요한 시스템에 접근하지 못하면 `자료가 없다`고 단정하지 않고 접근 실패 범위를 알려야 한다.

## 6. AI가 이상하게 답할 때
다음 명령으로 다시 기준을 확인시킬 수 있다.

- `BM_STARTER 다시 확인해`
- `PROJECT_READ 최신본 다시 읽어`
- `프로젝트 대장 다시 확인해`
- `공식 원본 기준으로 다시 검토해`

## 7. 완료보고에서 확인할 것
업무가 끝나면 AI는 실제 상태에 따라 아래 중 하나를 표시한다.

- `READ 저장·확인 완료`
- `READ 변경 없음`
- `READ 저장 미완료 — 사유와 복구할 내용`

결과물 파일 저장과 READ 기록은 별개이므로 둘 다 필요한 업무는 각각 확인한다.

## 8. 한 줄 사용법
**프로젝트명을 말하고 일을 시킨다 → 필요하면 `작업 결과 저장` → 끝낼 때 `마감` → 모르면 `매뉴얼`**
