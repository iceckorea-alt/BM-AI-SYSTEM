# 비엠업무 — 최신 원본으로 들어가는 입구

스킬 v3.13 · 2026-11-07 · 운영 규칙은 복제하지 않고 최신 공식 원본을 따른다.

1. 매 BM 업무 요청 시작(같은 채팅의 후속 요청 포함)에 Google Shared Drive `BM` 루트의 Google Docs `BM_STARTER` 현재 규정 버전을 다시 확인한다. 개인 Drive·백업·LEGACY·98·99 파일로 대체하지 않는다.
2. 처음이거나 적용 버전이 불명·변경됐으면 최신 STARTER 0장을 읽고 적용한다. 같은 버전이면 읽은 규칙을 재사용한다. 버전 변경 때만 `governance/AGENT_ONBOARDING.md` 1-1장의 변경 수용·자기 설정 갱신 절차를 따른다. 세부 원본은 `https://raw.githubusercontent.com/iceckorea-alt/BM-AI-SYSTEM/main/` + 경로다.
3. STARTER가 안내하는 INDEX → 지정 READ → 필요한 부록·원본 흐름, 역할·권한·기록·저장·시작/완료보고를 따른다. 전체 규칙·프로젝트 사실을 스킬이나 메모리에 복제하지 않는다.
4. 스킬·메모리 수정이 허용되면 BM 입구·적용 버전·확인일·동기화 상태만 최소 갱신하고 재조회한다. 호스트 정책·승인·정식 배포 절차를 지킨다. 불가능하면 최신 원본을 현재 업무에 적용하고 설정 갱신 미완료를 구분한다. 직원에게 변경 설명을 요구하지 않는다.
5. STARTER 접근 실패 시 최신 확인 실패를 보고하고 과거 기억으로 확정·쓰기를 진행하지 않는다. 실행 중이 아닌 AI로의 백그라운드 전파·자동 실행 기능은 없다.
