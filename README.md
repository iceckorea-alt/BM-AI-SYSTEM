# BM-AI-SYSTEM

BM Digital 1.0의 AI 운영 규정 공식 원본 저장소. 현재 규정 v3.0 (2026-10-21).

**AI는 `governance/BM_CORE.md`부터 읽는다.** 입구는 Google Shared Drive `BM` 루트의 `BM_STARTER`.

| 경로 | 내용 | 언제 읽나 |
|---|---|---|
| `governance/BM_CORE.md` | 공통 조약 1쪽 | 매번 |
| `governance/ops/` | 업무별 상세(프로젝트·마감·권한) | 해당 업무 때 |
| `governance/BM_DIGITAL_1.0.md` | 상위 원칙·우선순위 | 원칙 판단 때 |
| `governance/AGENT_ONBOARDING.md` | 사람·AI 투입·교체·회수 | 투입 때 |
| `governance/SYSTEM_HEALTH_CHECK.md` | 점검표 | 점검 때 |
| `templates/` | READ·결과보고서 서식 | 생성·마감 때 |
| `guides/` | 사용자 퀵가이드 | `매뉴얼` 요청 때 |
| `skills/` | AI 진입 스킬 원본 | 설치·갱신 때 |
| `CHANGELOG.md`, `archive/` | 변경기록·과거 문서 | 경위 확인 때 |
| `agents/`, `automation/`, `integrations/` | 역할·자동화·연동 문서(확정 시 추가) | 해당 시 |

공식 원본 구분: GitHub=AI 규정 / Drive=실무자료·PROJECT_READ / Sheets=BM_PROJECT_INDEX / Airtable=BM_ACCESS_REGISTRY / Docswave=행정·결재

Public 저장소다. 개인정보·계정정보·내부 리소스 ID·인증정보를 올리지 않는다.
