# PROJECT_RESULT_REPORT_TEMPLATE

템플릿 v3.0 · 2026-10-21 · 마감 절차는 `governance/ops/OPS_CLOSING.md`. 이 문서는 결과보고서 서식만 담는다.

**역할:** BM 프로젝트 마감 시 결과보고서(DOCX) 생성 기준  
**실제 결과보고서 형식:** DOCX 기본  
**실제 저장 위치:** 각 프로젝트 `05_성과·결과`  
**공통 DOCX 표준서식:** Google Shared Drive `BM/00_BM공통/03_공통규정·서식/BM_프로젝트_결과보고서_표준서식.docx`  
**권장 파일명:** `YYYYMMDD_결과보고서_프로젝트명.docx`

> 외부기관이 별도 결과보고·실적보고·정산 서식 또는 HWP/HWPX/PDF 제출형식을 지정한 경우 외부기관 기준을 우선한다.
> 본 템플릿은 서울시·자치구 지방보조사업 실적보고의 일반 구조와 BM 실무 필요를 반영한 내부 표준이다.

## 작성 원칙
- 공식 원본, PROJECT_READ, 실제 산출물에서 확인되는 사실만 사용한다.
- 확인되지 않은 사실·수치·참여인원·예산·성과를 추정해 채우지 않는다.
- 필수정보가 없거나 서로 충돌하면 결과보고서 확정 전에 사용자에게 질문한다.
- 질문은 가능한 한 관련 항목을 묶어 한 번에 확인한다.
- 외부 제출용 결과보고서는 발주·지원기관의 지정서식과 요구항목을 우선한다.
- 예산·정산 수치는 계약·결재·회계 원본을 근거로 한다.
- 사진·홍보물·참석자료·산출물 등 증빙은 실제 Drive 원본 링크를 연결한다.
- 결과보고서가 완성됐다는 사실과 실제 DOCX 파일이 저장됐다는 사실을 구분하여 확인한다.
