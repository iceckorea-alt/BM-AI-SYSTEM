# BM AI AGENTS v2.0

BM 업무는 BM_STARTER의 라우팅을 따른다.

프로젝트 업무 순서:
1. Google Sheets BM_PROJECT_INDEX 확인
2. Google Drive PROJECT_READ 확인
3. 실제 원본 확인
4. 업무 수행
5. 확정된 변화만 READ 갱신
6. 위치·상태·담당자·핵심 링크 변경 시 INDEX 갱신

공식 역할:
- GitHub: AI 운영지침·역할·Skills·자동화·연동문서
- Google Drive: 실무자료와 실제 PROJECT_READ
- Google Sheets: 프로젝트 중앙 인덱스
- Airtable: 계정·SNS·서비스 접속정보
- Docswave: 공식 행정·결재

추정 기록 금지, 공식 원본 우선, 삭제·대량이동·권한변경은 승인 후 수행한다.
