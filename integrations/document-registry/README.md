# BM 문서 수집기 v1.0

Drive 문서 파일의 메타데이터를 중앙 Google Sheets에 기록한다. 본문·도장 이미지 수집, 원본 이동/삭제, 자동 채번·결재·메일 발송 기능은 없다. 규정: `governance/ops/OPS_DOCUMENTS.md`.

## 설치
1. 비공개 INDEX 공통문서 → BM_문서관리대장 → 확장 프로그램 → Apps Script. 기존 메일수집 프로젝트에 붙여 넣지 않는다.
2. `Code.gs` 전체를 같은 이름 파일에 붙여 넣는다. 프로젝트 설정에서 매니페스트 표시 후 `appsscript.json`을 이 폴더 내용으로 교체한다. 기본 Cloud 프로젝트에서는 Advanced Drive 서비스가 매니페스트로 활성화된다. 별도 표준 Cloud 프로젝트를 쓰면 Drive API 활성화도 필요하다.
3. 대표 계정 한 명이 `BM_install` 실행·Google 권한 승인. 예약 실행은 설치한 계정 권한으로 동작한다. 다시 설치하면 같은 계정의 동일 함수 트리거 중복만 제거한다. 다른 계정의 기존 트리거는 설치자가 직접 제거한다.
4. 실행상태와 Apps Script 실행 기록에서 최초 수집 성공, 트리거의 BM_sync 15분 간격 1개, 후속 예약 실행 성공을 각각 확인한다. 대장 읽기·쓰기 및 BM 공유드라이브 읽기가 가능해야 한다.

구글 계정 승인 없이 로컬 코드만으로 예약 실행이 시작되지는 않는다. 배포 시 실제 상태는 대장의 실행상태를 기준으로 한다. API 연결에서 Apps Script 프로젝트 생성·실행을 지원하지 않으면 코드 준비와 구글 설치 미완료를 나누어 보고한다.

## 설정과 데이터 계약
설정 탭 1행은 키/값/설명, 이후 DRIVE_ID, ROOT_ID, EXCLUDE_IDS(쉼표 구분 폴더ID), SCHEMA_VERSION 등. 내부 ID·실제 문서 메타데이터는 공개 저장소에 넣지 않는다. `문서목록` 1행은 Code.gs의 BM_HEADERS와 정확히 일치해야 한다. A:I 자동 관측, J:M 수동 확정. 필터 범위·입력 검증은 새로 늘어난 행에서 필요하면 확장한다.

파일ID 단위 갱신. 복사본의 수동 필드는 비워 둔다. 중복 ID는 오류로 중단. 100개씩 페이지를 저장하고 ID를 재조회한 뒤 체크포인트 저장. 실패 시 같은 페이지를 재실행하므로 중복 행을 만들지 않는다. 약 210초마다 중단 지점을 저장하며 큰 드라이브는 여러 실행에 걸쳐 완료한다. 매 전체 순회가 끝난 뒤 다음 15분 실행에서 새 전체 순회한다. 동시 변경을 완전히 묶는 스냅샷이나 정확한 실시간 변경 이력은 제공하지 않는다. 변경이력 탭은 시스템·업무 판단의 기록이며 모든 파일 수정 이벤트 로그가 아니다.

원본 관측 실패 시 삭제 판정 없음. 완료한 순회에서 미관측 기존 행은 재확인 표시. 권한·폴더 경로 조회 실패는 오류로 표시하고 체크포인트 유지. 제목의 수식 문자는 텍스트 처리. 경로는 파일명 문자열 추정 대신 부모 ID로 계산한다. 대장 자체·제외 폴더 하위·문서 이외의 이미지/영상/ZIP는 수집하지 않는다. 제외 대상으로 이동한 기존 파일은 탐색용 제목·경로·링크 제거. 민감 문서를 추가로 제외하려면 설치 전 EXCLUDE_IDS에 상위 폴더ID를 추가한다.

## 검증
로컬 `node integrations/document-registry/tests.mjs`: 같은 ID 재시도, 이동/이름 변경, 수동 확정 필드 보존, 복사본 확정 미승계, 중복 ID 거부, 수식 텍스트 처리, 문서 형식 선별, 제외 폴더, 부모 경로, 접근 오류, 쓰기 실패 시 체크포인트 보존을 모의 검증한다. Google 권한·할당량·트리거는 로컬 모의 검증으로 확인할 수 없다.

구글 설치 후 실제 검증: 문서 1개 생성 → 전체 순회 → 이름 변경 → 폴더 이동(하위 문서 포함) → 복사 → 제외 폴더 이동 → 권한 오류 → 재실행 → 예약 실행을 확인한다. 실제 원본 삭제 없이 폐기용 테스트 문서만 사용한다. 대표 원본·기존 공문 번호를 테스트용으로 수정하지 않는다.

중지: 설치자의 이 Apps Script 프로젝트에서 BM_sync 트리거만 삭제. 메일수집 자동화는 별도 프로젝트로 유지한다.

공식 API 근거: [Advanced services](https://developers.google.com/apps-script/guides/services/advanced), [Drive files.list](https://developers.google.com/drive/api/reference/rest/v3/files/list), [Installable triggers](https://developers.google.com/apps-script/guides/triggers/installable).
