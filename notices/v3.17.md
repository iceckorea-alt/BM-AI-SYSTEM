# AI 공지 v3.17 — 조건형 문서 찾기·중앙 공문대장

2026-11-16 · 대상 모든 BM AI · 이전 공지 [v3.16](v3.16.md) · 대체됨: v3.16의 개별 서울/인천 원장 신규 입력 경로. 수집기 설치 대기는 계속 유효.

## 바뀐 것
첫 탭은 소속·업무 단계·프로젝트/업무·종류·역할·키워드 조건형 검색이다. 문서목록 기존 A:M은 보존하고 N:Q 수동 분류를 추가했다. 무조건 전체 문서를 펼치지 않는다. 업무 탭 6개와 숨긴 관리 탭을 구분했다. 데이터 삭제·원본 이동은 없다.

공문 등록은 중앙 공문대장 하나로 통합했다. 발행주체·연도로 번호를 구분하고 기존 개별 원장의 확인된 기록만 이관했다. 이전 원장은 이관 전 보존자료로 남기고 현행 원장을 안내했다. 원본 공문 내용·번호를 바꾸거나 승인을 추정하지 않았다.

## 모든 AI 조치와 확인
1. 최신 STARTER → INDEX 공통문서의 중앙 문서관리대장 → 찾기/공문대장으로 들어간다. 확인: 조건 선택 후 필요한 원본 링크가 나오는지 검증한다.
2. 문서 분류는 N:Q에 근거로 입력한다. 새 관측 파일의 분류가 비어 있으면 미분류로 둔다. A:I 자동 관측·J:M 업무확정 영역은 유지한다. 확인: 같은 파일ID의 기존 확정값과 분류가 수집기에 보존되는지 대조한다.
3. 공문 신규/수정은 중앙 공문대장만 사용한다. 기존 서울 원장·인천 이전 탭은 동시 수정하지 않는다. 확인: 원장 링크가 현행 중앙 탭인지 확인한다.
4. 공문은 관리ID로 결재·발송 행과 연결한다. 승인·발송 기록은 결재·발송에만 입력하고 공문대장 I/L/M 자동 보기를 직접 고치지 않는다. 확인: 동일 관리ID의 한 행과 자동 조회 값을 대조한다. 초안은 번호가 없어도 등록 가능하며 과거 이력 대조 전 자동 채번 금지.
5. 자기 AI적용 행만 갱신하고 저장 후 재조회한다. 다른 AI의 적용을 대신 완료 처리하지 않는다.

## 검증·가동 상태
인천+공문, 공통+서식+결과보고서 조건의 실제 구글 검색 결과와 중앙 공문 이관·상태 조회를 확인한다. 번호 중복/발송 증빙 누락은 조건부 경고이며 결재·발송 강제 차단 기능은 아니다. 전체 과거 공문 이력과 원본 링크·승인 근거는 추가 확인이 필요하다.

수집기 코드·권한 승인·구글 설치·실제 예약 실행은 여전히 구분한다. 자동수집은 설치 미완료이며 초기 확인된 일부 문서만 등록돼 있다. 숨긴 실행상태·설치안내를 확인하고 이미 다른 AI가 설치했는지 재개 전에 재조회한다. 메일수집 프로젝트는 이번 변경에 포함하지 않는다.

## 하지 말 것
개별 이전 원장과 중앙 원장을 이중 수정하지 않는다. 번호·승인·현재본·발송을 추정하지 않는다. 수식 보기를 값으로 덮어쓰지 않는다. 미설치를 자동 운영 중이라고 보고하지 않는다. 규정 변경 전문을 각 AI 설정에 복제하지 않는다.
