# AI 공지 v3.18 — 별도 통합 공문대장
2026-11-18 · 대상 모든 BM AI · 이전 공지 [v3.17](v3.17.md). 대체됨: 일반 문서관리대장 안의 구 공문 탭·개별 원장 보존 안내·초안 정식 등록 방식. 일반 문서 검색·분류와 수집기 설치 대기는 유지.

## 모든 AI 조치
1. 최신 STARTER → INDEX 공통문서 → 별도 BM_공문대장. 발신공문은 OPS_OFFICIAL_LETTERS를 읽고 누락된 내용만 질문한다. 확인: 현행 원장이 독립된 구글시트이며 구 공문 탭/삭제 대장을 참조하지 않는지 확인.
2. 초안은 INDEX 할일, 최종승인 후 번호 재확인·확정 시 발신대장에 등록. 예정번호는 확정이 아니다. 단일 창구 직렬 확정, 과거 이력·번호기준 미검증 상태의 자동 채번 금지. 확인: 발행주체·연도·번호·관리ID 중복 및 저장 재조회.
3. 지정 HWPX 서식 표 보존·한글 확인, 승인 후 날인 PDF. 같은 번호 수정본·중요변경 재승인·과거 파일/메일 보존. 현재버전ID가 발송이력과 일치하는지 확인.
4. 여러 기관 CC는 메일 한 건 단위. 연결된 AI만 임시보관 준비 가능하며 실제 전송은 사람이 함. 보낸메일ID/링크·발송시각·첨부 확인 후 완료. 반송·재발송·임시보관을 구분. 확인: 자동 상태와 실제 증거 대조.
5. 보관폴더·HWPX·PDF·메일 링크, 관련 수신공문, 회신기한 INDEX/Calendar 연결을 확인. 캘린더 설정 전 등록 대기, 기본 3일 전·당일. 일부 회신은 완료 금지.
6. 자기 AI적용 행만 갱신·재조회. 다른 AI의 적용을 대신 완료 처리하지 않는다.

## 배포·검증 상태
운영 규칙 모의검증 38개 및 실제 구글시트 수식의 임시보관/발송·날짜·링크/반송/수정버전/번호중복/다대다 연결을 확인하고 시험 행 제거. 기존 공문 기록을 대조 이관하고 현행 위치 안내를 바꾼 뒤 구 공문대장만 정리한다. 실제 공문·수정본·증빙은 삭제하지 않는다. 작업 완료 여부는 비공개 대장 운영안내·INDEX에서 재조회한다.

현재 시트·입력검증·경고·운영 규칙을 구축했다. 자동채번 잠금, Gmail 임시보관/발송 자동화, 수신 자동 접수, Calendar 이벤트/알림, 계정 기반 승인권한 검증은 실가동 완료가 아니다. 기존 문서수집기도 별도 설치 대기다. 38개 모의 통과를 실제 외부 연동 성공으로 설명하지 않는다.

## 금지
구 원장과 이중 수정, 초안 정식 등록, 취소번호 재사용, 수정본에 이전 발송완료 승계, 승인/전송 추정, 실제 공문·증빙 삭제, 자동 계산열 덮어쓰기, 미접속 AI 적용 완료 대리 기록 금지.

## 2026-11-25 운영 후속 — AI 업무지시서 분야별 정리
기존 v3.18의 단일 원본·선택 조회·Google Docs 원칙을 적용한 보관·연결 정리다. 별도 입구·INDEX·공지판이나 프로젝트 체계를 만들지 않았다.

- 모든 AI: 기존 STARTER → INDEX `공통문서`에서 분야·필요할 때·읽을 절을 보고 해당 지시서만 연다. 상시업무의 기존 READ/LOG 진입도 유지한다. 지침 폴더 전체와 과거본은 기본으로 읽지 않는다.
- 브랜드·웹·홍보/SNS·콘텐츠제작의 기존 지시서·운영문서를 분야별 공통 지침 영역에 모았다. 기존 파일은 ID와 링크를 유지했고, 반복 수정하는 제작 지침 한 건만 Google Docs로 전환해 새 ID를 기존 INDEX에 연결했다. 구 MD에는 현행 링크를 남겨 아카이브에 보존했다.
- 기존에 고정 참고로 등록한 SNS MD 부록 두 건은 본문과 ID를 유지한다. 과거 조사·설정 체크리스트이며 현재 정책·실계정·실가동의 증거가 아니다. 실행 전 관련 공식 자료와 실제 상태를 확인한다.
- Google Docs인데 이름만 `.md`였던 시리즈 지침은 같은 ID로 역할명 `_GUIDE`로 정리했다. 개별 편의 자료·미디어·프로젝트 원본은 기존 위치를 유지한다.
- 확인: INDEX의 기존 링크·실제 파일ID/부모폴더·Docs 형식·전환 본문·지침 연결을 대조한다. 세부 처리·백업·검증 결과는 비공개 문서대장과 운영 LOG에서 확인한다.
- 하지 말 것: 이번 정리를 프로젝트 생성·할일 복구·계정/권한 변경·새 자동화·게시/광고·서버/배포 변경 승인으로 해석하지 않는다. 문서수집기 설치 대기와 Gmail/Calendar 등 미연동 상태는 그대로이며 다른 AI의 적용 완료를 대신 기록하지 않는다.

읽는 양: 추가 필수 파일 0개. 폴더 이동 자체의 본문 절감은 0이며, INDEX에서 필요한 지시서·절을 선택한다. 새 안내가 붙은 문서는 그 업무로 열 때만 추가로 읽는다.
