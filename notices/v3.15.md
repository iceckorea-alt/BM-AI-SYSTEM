# AI 공지 v3.15 · 2026-11-11

이전 공지: v3.14
대체됨: 없음

## 바뀐 것
- AI 간 업무 연속성을 위해 기존 프로젝트의 제작·수정·검토·정합·준비 업무에 **작업 시작 게이트**와 **종료 인계 게이트**를 추가했다.
- 시작은 `INDEX 해당 할일 → READ → 작업진입 → 필요한 실무원본` 순서다. 기존 결과물이 있으면 처음부터 다시 제안하지 않고 현재 지점에서 이어간다.
- INDEX `할일`에 `작업진입` 열을 추가했다. 기존 결과물을 이어가는 업무에만 첫 진입점 한 곳을 지정하며, 단순 전화·회신대기·참석·입금확인은 비워도 된다.
- 중단한 `진행` 작업은 비고에 `재개: 완료 지점 → 다음 행동`, 외부 의존 `대기`는 `대기: 대상/조건`을 남긴다.
- 별도 인수인계 문서를 만들지 않는다. READ=최신 판단·진입경로, 부록=분야별 상세·문서 역할 지도, INDEX=할 일·작업진입·재개지점, LOG=변경 경위 역할을 유지한다.
- 특정 AI의 Library·대화·내부 결과 링크는 보조참고로만 사용하며 여러 AI가 이어받을 핵심 작업자산의 유일한 원본으로 쓰지 않는다.
- 할일ID 중복은 오류다. 시스템관리는 나중에 생성된 중복 행을 다음 미사용 번호로 정정한다.

## 조치
### 모든 AI — 사람·도구마다
1. 기존 프로젝트에서 무언가를 새로 만들거나 수정·검토하려 할 때, 먼저 해당 열린할일의 `작업진입`과 READ를 확인한다.
   - 확인 방법: 기존 결과물이 있으면 새로 시작하자는 제안 대신 현재 재개지점에서 이어간다.
2. 작업을 끝내지 못하고 중단하면 INDEX 비고에 필요한 `재개:` 또는 `대기:`를 남긴다.
   - 확인 방법: 다른 AI가 대표에게 이미 한 일을 다시 묻지 않고 이어갈 수 있어야 한다.
3. 기존 할 일을 일괄 소급 수정하지 않는다. 실제로 다시 손대는 진행 업무부터 작업진입·재개지점을 보완한다.
4. INDEX `AI적용` 탭의 자기 사람·도구 행을 v3.15로 갱신한다.
   - 쓰기 권한이 없으면 넣을 한 줄을 보고하고 적용 자체는 최신 원본 기준으로 수행한다.

## 하지 말 것
- 별도 HANDOVER·AI메모 문서를 프로젝트마다 만들지 않는다.
- 과거 체크리스트·초기안을 현재 상태처럼 다시 써서 과거 기록을 훼손하지 않는다.
- 특정 AI만 접근할 수 있는 링크를 유일한 작업진입으로 만들지 않는다.
- 행사 파일의 이름·번호·운영내용을 인계 구조 개선을 이유로 임의 변경하지 않는다.
