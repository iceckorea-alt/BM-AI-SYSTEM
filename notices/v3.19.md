# AI 공지 v3.19 — 독립 사업발굴 원장
2026-11-25 · 대상 모든 BM AI · 이전 공지 [v3.18](v3.18.md).

## 실행 조치
1. 최신 STARTER → 기존 INDEX 공통문서 → BM_DISCOVERY_INDEX로 진입한다. 구 사업발굴/보관 탭은 전환 안내·보존용이며 신규 입력 금지.
2. 사업발굴 업무 때만 OPS_DISCOVERY와 사업발굴 GUIDE의 해당 절을 읽는다. 연도별 원장이 단일 원본이며 분기집계·검토대상·마감임박을 직접 수정하지 않는다.
3. 전체 연도 ID/중복키·유사 사업·기존 프로젝트를 재조회하고 직렬 등록한다. 공식 사실·자격·AI 제안·대표결정을 분리한다. 대표 승인 전 프로젝트 생성 금지.
4. 기존 주간조사를 참조하고 새 자동조사는 만들지 않는다. 과거 보고·현재 예약 활성·다음 실행·신규 원장 연동을 혼동하지 않는다. 자기 AI적용 행만 실제 확인 결과로 갱신한다.

## 검증·가동 상태
연도별 원장, 분기집계, 선택 보기, ID/키 중복경고, 마감 경계와 전환 필수값 경고를 실제 Sheets에서 검증하고 임시행을 제거했다. 기존 원장·보관과 자료는 백업·대조하고 구원장은 보존한다. 실제 공고를 시범등록했으며 자격·대표 참여결정은 별도 미확정이다. 구글 렌더 화면 확인은 도구 연결 오류로 제한되어 원본/계산/스타일 메타데이터 확인과 구분했다.
기존 예약 활성상태·다음실행·신규 원장 쓰기연동, 동시등록 자동잠금, 실제 프로젝트 전환은 실가동 확인 완료가 아니다. 조사대상 중 공식 게시판/개별조사 미완료와 기존 계획자료 본문·요약 미완료는 비공개 원장에 표시한다. 권한·결제·자동화 중단·새 예약 생성 없음.

## 읽는 양
일반 업무의 추가 필수 파일 0개. 사업발굴은 기존 INDEX의 전체 사업 탭 대신 독립 원장의 필요한 보기/행만 읽는다. 신규 GUIDE·OPS는 해당 업무 때만 선택 조회한다. 실제 본문 문자 증감은 비공개 운영안내에 기록하며 토큰 절감률은 실측하지 않았다.
